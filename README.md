# CoinNote
CoinNote
> **伟大钱程，我自己挣。**
一句话定位
不是记账 App，是花钱疼痛放大器。
你花 18 块买杯奶茶，它不告诉你「餐饮支出 ¥18」，它告诉你：这杯奶茶 = 你 13 分钟的命。
备考党、打工人、 side-hustler 专用。极简 3 秒记账，自动换算劳动时间，储蓄目标拆解到每天，月底一键生成朋友圈账单。

核心公式：消费 = 劳动时间。输入你的时薪，所有支出自动换算。支持自定义锚定物（如鸡蛋 1 元），奶茶 = 18 个鸡蛋，放在首页最显眼位置。
---
3 秒上手
1. 设置你的时薪（首次必做）
打开 → 底部「设置」→ 「劳动换算」→ 输入时薪（如 ¥80/小时）
> 💡 时薪 = 月兼职收入 ÷ 月工作小时。不知道就填个大概，随时改。
2. 记一笔
首页 → 右下角「+ 记一笔」→ 选类别 → 输金额 → 确认
> 💡 输入正数 = 支出，前面加负号 = 收入。支持自定义类别，在设置里添加。
3. 看伤害
首页每笔支出右侧自动显示「≈ XX 分钟劳动」。储蓄目标进度条实时更新。
4. 月末复盘
底部「月度」→ 支出分布饼图（按金额 / 按劳动时间双维度切换）→ 高频小额洞察 → 频次涨跌对比 → 全部明细列表
5. 发朋友圈
月度页 → 「生成月度账单卡片」→ 长按截图 → 发朋友圈
目标页 → 「生成储蓄进度卡片」→ 长按截图 → 发朋友圈

核心功能详解
💰 记账（支出 / 收入）
自定义类别 + emoji 图标，奶茶、咖啡、地铁都能记
收入前自动加 `+` 号，支出生成劳动换算
历史记录点击可编辑、删除
长按/滑动支持快捷操作（未来版本）
⏱ 劳动时间换算
输入时薪，每笔支出自动显示「≈ XX 分钟劳动」
支持自定义锚定物：物品名 + 单价，启用后替代劳动分钟（如鸡蛋 1 元，奶茶 = 18 个鸡蛋）
放在首页最显眼位置，替代抽象金额
🎯 储蓄目标
输入目标金额 + 截止日期（如雅思报名 ¥2000，2026-08-01）
自动计算：距目标还有 X 天，每天需存 ¥Y ≈ Z 分钟劳动
进度条实时更新，目标页一目了然
支持多目标管理
📊 月度洞察
支出分布饼图：按金额 / 按劳动时间双维度切换
高频小额洞察：自动识别 ≤¥10 高频消费，蚂蚁搬家搬的是我的家
频次涨跌对比：本月 vs 上月各类别消费次数，↑ 变坏 ↓ 变好
全部明细：所有记录按时间倒序，点击可编辑
📤 分享卡片
月度账单卡：支出 / 收入 / 余额 + 分类饼图 + 日期水印
储蓄进度卡：目标名 + 进度条 + 剩余金额 + 每日拆解
长按截图发朋友圈，配 slogan「伟大钱程，我自己挣！」

安装
PWA（推荐，零成本）
手机浏览器打开 `https://sunjy2026.github.io/CoinNote/`
浏览器菜单 → 「添加到主屏幕」/「Add to Home Screen」
桌面出现 App 图标，点开全屏运行，和原生 App 没区别
Android APK
仓库含 Capacitor Android 工程，Android Studio 打开 → Build → 出 APK，发给朋友直接安装。
